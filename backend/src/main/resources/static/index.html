About the Project

Overflowing bins and missed collections are often reported manually and are hard to track. CleanTrack provides one place for citizens, administrators and waste collectors to handle every complaint transparently.

Features

Submit Complaints

Add a description and location in seconds.

Track Status

Pending, Assigned, In Progress, Resolved.

Admin Control

Assign collectors and manage complaints.

Collector Dashboard

See assigned work and update progress.

Feedback & Rating

Rate the service after resolution.

Secure Access

Role-based access with BCrypt passwords.
